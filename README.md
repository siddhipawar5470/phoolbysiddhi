# Phool by Siddhi — React Website

A responsive one-page festive floral décor website built with React + Vite.

## Run locally

1. Install Node.js 20.19+.
2. Open this folder in VS Code / Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Important customization

Open `src/main.jsx` and replace:

```js
const WA_NUMBER = "919999999999";
```

with the business WhatsApp number in international format, without `+` or spaces.

You can also change product names, prices, descriptions and image URLs in the `products` array.

The sample photos use remote image URLs so the starter project stays lightweight. For the final business website, replace them with your own real decoration photos.

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.
